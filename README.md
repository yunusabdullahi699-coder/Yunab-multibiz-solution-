# Yunab Multibiz Solution Frontend

A modern, responsive frontend landing page for **Yunab Multibiz Solution**.

## Features

- Responsive navigation with mobile menu
- Hero, services, about, portfolio, and contact sections
- Clean modern styling with reusable utility classes
- Contact form interaction (client-side demo behavior)

## Run locally

Because this is a static frontend, you can serve it with any static server.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in your browser.
